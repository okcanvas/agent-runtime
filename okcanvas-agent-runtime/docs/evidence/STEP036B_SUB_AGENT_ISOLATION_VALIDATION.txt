Binding isolation model

2. invocation/state isolation: always
3. physical workspace/session isolation: only when filesystem capabilities are enabled

Workspace rules
- no shared writable parent/child root by default
- transfer only typed input, filtered history, immutable snapshot/mount, Artifact, or bounded result
- runtime-generated opaque workspace roots
- no model-selected host path or mount
- Session, protected payload, workspace, and long-term memory are separate lifecycles
- host folder separation alone is not hostile-code containment
