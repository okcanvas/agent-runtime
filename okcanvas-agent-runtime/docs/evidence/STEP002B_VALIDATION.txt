STEP002B_WINDOWS_ENV_LOADER_FIX VALIDATION
Date: 2026-07-28
Version: 0.2.2

Confirmed original defect
- STEP002A sh_doctor.cmd and sh_run_step002_live_acceptance.cmd used:
  if exist ".env.local.cmd" call ".env.local.cmd"
- Therefore malformed, wrapped, or plain-text lines in the local file were executed by cmd.exe.

Implemented correction
- Batch launchers no longer call or execute local environment files.
- scripts/windows_entrypoint.py parses .env.local or legacy .env.local.cmd as data.
- Only OPENAI_API_KEY, OKCANVAS_AGENT_MODEL, OKCANVAS_CODEX_MODEL, and CODEX_PATH are allowed.
- UTF-8, UTF-16 BOM, and CP949 are supported.
- Unknown variables, prose, duplicates, malformed quoting, and dual local files fail closed.
- Secrets are passed only through the child environment, not command arguments.
