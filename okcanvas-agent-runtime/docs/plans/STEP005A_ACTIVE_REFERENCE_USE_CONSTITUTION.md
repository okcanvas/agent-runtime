## Objective

Make active use of the immutable `/reference` source a binding project constitution rather than an optional research practice.

## Scope

- update `AGENTS.md`;
- update product-level constitution and adoption workflow documents;
- update baseline and HANDOFF metadata;
- add executable regression coverage for the constitution;
- preserve all reference tree hashes.

## Non-scope

- no runtime feature, Agent, Codex, MCP, API, database schema, or UI change;
- no modification of `reference/upstream/**`;
- no implementation of STEP006.

## Acceptance

- constitution explicitly requires active reference consultation;
- relevant capability categories are named;
- adopt/adapt/defer/reject recording is required;
- full tests pass;
- reference verification passes;
- source ZIP and SHA-256 are generated.
