# OKCanvas Connector Examples

Optional executable construction guides for organizations implementing external systems consumed by
OKCanvas Connectors. Nothing here is a production dependency, an authoritative enterprise-system
implementation, or an MCP replacement.

- `groupware/groupware-api-fake`: Groupware product REST/API construction example.
- `organization-context/organization-context-api-fake`: mutable Organization Context product API
  construction example with ambiguity, revision, change feed, CAS, and tombstone.
