# JSON Reference Dataset

The Example loads `fixtures/{tenant}/manifest.json`, then validates every declared JSON collection before serving requests.

Validation includes expected counts, stable-ID uniqueness, tenant isolation, employee/department/position references, product and client ownership, project references, capability-to-system references, and every relation endpoint.

The committed JSON files are reviewable examples of how an organization can represent directory, product, client, glossary, system, capability, project, and relationship data. They are not the production persistence recommendation.
